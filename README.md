# 会话与分组清理

持久化 DSH 插件：在会话的“…”菜单增加“彻底删除…”，并在左侧底部增加“会话清理”按钮。打开清理面板后可切换“会话 / 分组”，查看完整删除清单，再执行永久删除。

## 使用

1. 单个会话：左侧会话“…” → “彻底删除…”。
2. 整个分组：左侧底部“会话清理” → “分组” → 对应分组“查看删除清单”。
3. 核对会话数、文件与目录，以及保留文件说明，然后点击“彻底删除”。
4. 完成后可点击“刷新左侧列表”。运行中的会话须先停止，清单过期或内容发生变化时重新预览。

## 清理内容

- 选中会话的本地 JSONL 数据目录，包含保留的日志版本。
- 对应会话投影缓存；搜索索引按当前 Host 的重建接口清理。
- 有明确创建记录、仍与追踪内容一致、且未被保留会话使用的本地生成文件。
- 删除分组时，处理该分组内的会话并移除分组注册。

原有工作目录和原有文件保留。共享文件、链接、后来被外部修改的文件及归属证据不足的文件会保留，清单中给出说明。历史上仅通过 shell 生成、且日志未保留创建证据的文件可能需要另外清理。安装后，插件会追踪文件工具和 shell 在会话工作目录内生成的文件；扫描有数量上限，不进入依赖目录及受保护的 DSH/插件目录。

## 实现与兼容性

浏览器端通过官方 Slot 增加入口，所有数据操作走 Host 的同一份 SessionCleaner 实现。浏览器请求经过当前 Connection 的认证入口；Agent 可使用 `session_cleanup` 工具的 `list / preview / delete` 操作。工具删除当前调用会话时会返回明确状态，避免清理尚在执行的日志。

当前 DSH 的 SessionPersistence 没有公开删除接口。因此本插件将 JSONL 数据定位和有序生命周期清理封装为版本适配层；适配检查失败时，预览会说明原因，并保留目标数据。DSH 更新后应重新验证此适配层。

插件无安装脚本，无额外运行依赖。图标为本插件原创 SVG。语言资源包含中文及英文。

## 本地验证

使用 Node 内置测试运行器执行 `node --test artifacts.test.js backend.test.js`。所有删除测试都在独立临时目录内进行，不操作用户已有会话。
